# SesliOda — Gerçek Zamanlı Mesajlaşma ve Sesli Sohbet Sunucusu

Bu paket, arkadaşlarınla farklı cihazlardan yalnızca `@kullaniciadi` yazarak mesajlaşabilmen ve tek tıkla sesli arama yapabilmen için gereken tam sunucu kodunu içerir.

## Bilgisayarında Hemen Çalıştırma
1. Node.js (v18+) kurulu olduğundan emin ol.
2. Bu klasörde terminali aç ve şu komutları çalıştır:
   ```bash
   npm install
   npm start
   ```
3. Tarayıcıdan `http://localhost:3000` adresine gir.

## İnternette Ücretsiz Yayınlama (Arkadaşlarının Her Yerden Bağlanması İçin)
1. Bu klasörü bir GitHub deposuna yükle.
2. **Render.com** veya **Railway.app** üzerinde yeni bir **Web Service** oluştur.
3. **Build Command:** `npm install` — **Start Command:** `npm start` olarak ayarla.
4. Oluşan `https://...` bağlantısını arkadaşlarınla paylaş. Herkes kendi `@kullaniciadi` ile giriş yapıp birbirini **Kullanıcı Adı ile Arkadaş Bul** penceresinden görerek mesajlaşabilir ve sesli arayabilir.
